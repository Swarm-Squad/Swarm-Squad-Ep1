# Getting Started (GUI-First Track)

This quick start is for users who want to run and learn from the web GUI without writing Python scripts.

## 1) Start the runtime

From project root:

```bash
uv run swarm-squad-ep1
```

Open:

- `http://localhost:5000`

## 2) Run your first GUI scenario

1. Choose formation/path/comm model in the right panel.
2. Add one jamming or spoofing zone.
3. Toggle encryption on/off.
4. Press **Start** and observe:
   - swarm movement,
   - jamming/spoofing overlays,
   - attack metrics and protocol stats.

## 3) Compare scenarios

Try these fixed-variable comparisons:

- low-power vs high-power jamming,
- spoofing type (`phantom` vs `coordinate` vs `position_falsification`),
- encryption OFF vs ON.
