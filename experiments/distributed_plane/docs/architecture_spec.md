# Stage 2 — Distributed architecture specification

**One LLM agent per vehicle, coupled by a command-authority hierarchy**
Successor to Fig. 1 ("Overview of the dual MASS architecture") of the IEEE TVT submission.
Target venue: IEEE ICC 2027. Companion figure: `architecture.png`. Axis labels (A1–A9) refer to the Stage 1 matrix.

---

## 0. What this replaces, and why

The TVT architecture places **one** LLM supervisor above the swarm. It consumes global telemetry,
fires on a trigger (sustained drop in average link quality `J_n`, repeated jamming detections, or waypoint
stagnation), and its output is fused into each affected agent's controller by Algorithm 2:

```
C_f[i] = w_l * C_l[i] + (1 - w_l) * C_b[i],    w_l = w_min + (w_max - w_min) * s_i,   w_min=0.3, w_max=0.8
```

Three properties of that design are what Stage 2 has to change.

| Property of TVT Fig. 1 | Consequence | Stage 2 replacement |
|---|---|---|
| Single reasoning locus above the swarm | One jammed uplink or one bad generation degrades every vehicle at once | N reasoning agents, one per vehicle, each with authority over its own actuator only |
| Authority is a **continuous gain** `w_l(s_i)` | An unsafe LLM output is never rejected, only attenuated — at `s_i≈1` it carries 80% of the command | Authority is a **discrete lattice** `A0..A4`; a proposal is admitted or discarded, never partially applied |
| Severity `s_i` *scales* LLM influence | Trust rises exactly when telemetry is least reliable | `s_i` becomes a **precondition** that unlocks higher authority levels, not a gain on the command |
| Reasoning traffic is supervisor↔swarm | No peer disagreement exists, so no Byzantine reasoning fault is expressible | Peer reasoning plane over an r-robust subgraph; disagreement is the signal the filter consumes |
| Trust is implicit (single trusted supervisor) | Semantic-layer faults are out of scope by construction | Receiver-side evaluation only; no sender-declared field is authoritative |

The one-line statement of the change: **in TVT the LLM is a supervisor whose advice is blended; here the LLM
is a proposer whose advice is admitted.**

## 2. Vehicle-local layer stack

Every vehicle carries the same five-layer stack. Layers are ordered by rate and by determinism: everything
below L2 is deterministic and hard-real-time; everything above L2 is stochastic and best-effort. **L2 is the
only downward path.**

| Layer | Function | Rate | Deterministic | Behaviour if it stops |
|---|---|---|---|---|
| **L4 Operator** | MCP-style command interface, graduated autonomy levels, audit log | asynchronous, rare | yes (commands are typed) | Autonomy continues at its last configured level |
| **L3 Reasoning agent** | Per-vehicle LLM. Consumes local telemetry digest + neighbour proposal records; emits one typed proposal | `1/Δt` (0.2–2 Hz) | **no** | Vehicle degrades to A1/A0; no other vehicle is affected |
| **L2 Admission gate** | Schema check → envelope check → evidence check → arbitration. Emits `(a*, u_i)` | control rate | **yes** | Fail-closed: no proposal is admitted, A1/A0 continue |
| **L1 Deterministic core** | `u_i = G_i + M_i`, tangent escape `T_i`, local replanning | 10–50 Hz | yes | Vehicle is uncontrolled — this is the only single point of failure that remains, and it is local |
| **L0 Plant / channel** | `q̇_i = u_i`; link-quality and jamming measurement feeding `s_i`, `J_n` | continuous | — | — |

Two rules make the stack analysable:

- **R1 (non-blocking).** L1 never waits on L2, L3 or the network. It runs on the last admitted command, or on
  its own output if none is admitted.
- **R2 (single downward interface).** No layer above L2 can write to L1 state. There is no side channel from
  the reasoning plane to the actuator — this is what makes INV1 checkable by inspection rather than by testing.

## 3. Two planes: the double multi-agent system

The system is two graphs over the same vehicle set, carrying different content at different rates.

**Vehicle plane `G_v(t)`** — numeric. Edges exist where the effective link quality exceeds the threshold used
by the formation controller. Content: positions, velocities, link quality. Rate: control rate. This plane is the
TVT system, unchanged; its edge dynamics are already driven by jamming.

**Reasoning plane `G_r(t) ⊆ G_v(t)`** — natural language, compressed to a compact record schema (Stage 3).
Content: proposal records. Rate: `1/Δt`. `G_r` is deliberately a *subgraph*: reasoning traffic is expensive on a
contested link, so it is carried only over edges selected to keep `G_r` robust rather than merely connected.

**Coupling.** Upward: L0/L1 telemetry is summarised into the digest that L3 consumes. Downward: only through
the L2 gate. Sideways: reasoning agents talk only to reasoning agents; controllers talk only to controllers.
Raw LLM text is never placed on the vehicle plane, and numeric control state is never placed on the reasoning
plane except as a digest.

**Swarm-size constraint (design finding).** Receiver-side filtering that tolerates `F` Byzantine proposers
needs each vehicle to retain at least one honest proposal after discarding `F` extremes from each side, so
`|N_i^r| ≥ 2F+1`, hence `N ≥ 2F+2`. For the stated range `N = 3..7`:

| N | Max tolerable F on a complete `G_r` | Consequence |
|---|---|---|
| 3 | 0 | No Byzantine filtering is possible. A3 is permanently unavailable; the swarm runs on A2/A1/A0 |
| 4–5 | 1 | `G_r` must be complete or near-complete — sparsification competes directly with robustness |
| 6–7 | 1 (2 only at N=6,7 with high degree) | First sizes where a *sparse* r-robust `G_r` is meaningful |

This is worth stating in the paper rather than hiding: it makes `N = 3` an honest ablation point that shows the
gate alone (without quorum) still bounds the damage, and it makes `N = 6,7` the operating point where the
Byzantine machinery earns its bandwidth.

## 4. Command-authority hierarchy

Five levels, strictly ordered. Each level names the evidence it requires and the class of action it may
authorise. Higher impact demands stronger evidence — this is the monotonicity that replaces the severity gain.

| Level | Source | Evidence required | Action class it may authorise | Availability |
|---|---|---|---|---|
| **A4** Operator | Human via MCP interface | Operator identity + autonomy level permits it | Anything, including suspending A2/A3 for named vehicles | Whenever the operator link is up |
| **A3** Quorum override | ≥ `F+1` mutually consistent peer proposals surviving the receiver-side filter | Quorum certificate over `N_i^r` | High-impact: formation break, altitude-band change, role/goal reassignment, egress heading | Only if `|N_i^r| ≥ 2F+1` |
| **A2** Local override | Own L3 agent only | Valid schema + inside envelope + fresh (`age ≤ τ_max`) | Low-impact: heading and speed adjustment within the envelope, waypoint bias | Whenever L3 is responsive |
| **A1** Reactive escape | L1, deterministic | Jamming detected (`s_i > 0`) | Tangent escape `T_i` | Always |
| **A0** Nominal | L1, deterministic | — | `u_i = G_i + M_i` | Always |

**Arbitration rule.** Let `Adm_i(t) ⊆ {A0..A4}` be the levels whose evidence conditions hold at time `t`. Then

```
a*_i(t) = max Adm_i(t)
u_i(t)  = Π_{S_i(t)} ( u^{a*_i(t)}_i(t) )
```

Three things follow directly, and each is a claim the Stage 1 matrix showed nobody else makes:

1. **No blending.** Exactly one source commands the vehicle at any instant. The command that reaches the
   actuator is always attributable to one level and one proposal record — which is what makes the audit log
   meaningful and the determinism metric (A9) measurable at all.
2. **Envelope containment is unconditional.** `Π_{S_i}` is applied after arbitration, so it binds A4 as
   tightly as A2. An operator command that would drive a vehicle into terrain is clipped exactly like an LLM
   proposal.
3. **Severity no longer buys authority.** `s_i` appears only in A1's condition and in the *freshness* budget.
   Deep jamming does not increase how much the LLM is trusted; it increases how often the deterministic escape
   fires.

**Relationship to TVT Algorithm 2.** Setting `Adm_i = {A0, A2}`, replacing `Π_{S_i}` with the identity, and
replacing selection with the convex combination `w_l C_l + (1-w_l) C_b` recovers the TVT controller exactly.
That is the natural **B1 baseline** for Stage 7: same per-vehicle LLM, same prompts, blended instead of gated,
which isolates the contribution of the gate from the contribution of distributing the LLM.

## 5. Interfaces

| ID | Producer → consumer | Rate | Payload | Fixed in |
|---|---|---|---|---|
| **I1** | L0/L1 → L3 (local) | `1/Δt` | Telemetry digest: own pose, `s_i`, `J_n` locally observed, neighbour poses and link qualities, current waypoint, active envelope bounds | Stage 2 (fields), Stage 3 (encoding) |
| **I2** | L3 → peer L3 over `G_r` | `1/Δt` | Proposal record: proposer id, sequence number, timestamp, intent class, parameters, own-evidence summary, requested authority level | Stage 3 |
| **I3** | L3 → L2 (local) | `1/Δt` | Own proposal, identical schema to I2 | Stage 3 |
| **I4** | L2 → L1 (local) | control rate | Admitted command: `u`, granted level `a*`, certificate reference, expiry | Stage 2 |
| **I5** | L2 → audit log | on every decision | Inputs hash, admitted/rejected, reason code, `a*`, proposal ids | Stage 2 |

Note the deliberate identity of I2 and I3: a vehicle's own proposal enters the gate through the same schema and
the same checks as a peer's. There is no privileged local path — a vehicle can be wrong about itself.

**Non-authoritative fields.** Anything in I2 that the sender asserts about its own trustworthiness (confidence
scores, self-reported severity, claimed priority) is advisory input to the receiver's own scoring, never a
multiplier applied as sent. Stated as an invariant in Sec. 7.

## 6. Timing and staleness

```
T_ctrl  (10–50 Hz)   <<   T_msg + T_filter   ≤   Δt   (0.5–5 s)
```

- A proposal older than `τ_max` is discarded by L2 without evaluation. Suggested `τ_max = Δt`, so at most one
  generation of proposals is ever live.
- L3 inference and peer exchange are asynchronous with respect to L1. A late proposal is not applied late; it
  is dropped.
- A granted A2/A3 command carries an expiry. On expiry, `a*` falls to A1/A0 unless renewed. **Authority decays
  to the deterministic floor by default** rather than persisting — this is what prevents a single admitted
  proposal from steering a vehicle indefinitely after its proposer is jammed or silenced.

## 7. Invariants

The architecture is designed so these are enforced structurally, not by testing:

- **INV1 (Envelope containment).** For all `t`, `u_i(t) ∈ S_i(t)`, for every authority level including A4.
  Guaranteed by applying `Π_{S_i}` after arbitration, and by R2 (no path bypasses L2).
- **INV2 (Gate determinism).** L2 is a pure function of (proposal set, telemetry digest, envelope, clock).
  Identical inputs give an identical `(a*, u)`. All stochasticity is confined to L3.
- **INV3 (Monotone evidence).** A higher-impact action class never requires weaker evidence than a lower one.
- **INV4 (No self-certification).** No sender-supplied field is used as an authority multiplier; trust is
  computed receiver-side from observed behaviour and cross-neighbour consistency.
- **INV5 (Liveness floor).** `Adm_i(t) ⊇ {A0}` always; A1 additionally whenever `s_i > 0`. The admissible set
  is never empty, so no vehicle can be stalled by the failure, silence, or capture of any reasoning agent.

INV1 + INV5 together are the paper's safety claim: *the swarm never executes an unsafe override, and never has
nothing to execute.*

## 8. Degradation ladder

| Condition | Detected by | Response | Highest available level |
|---|---|---|---|
| Nominal | — | Quorum-backed coordination | A3 |
| Own L3 slow / OOM | Inference deadline missed | Drop own proposal; still consume peers | A3 |
| Own L3 emitting invalid schema | L2 schema check | Reject, log, mark own agent degraded | A1 |
| Reasoning plane partitioned, `\|N_i^r\| < 2F+1` | Neighbour count | Quorum unavailable | A2 |
| `F` peers Byzantine | Receiver-side filter (Stage 5) | Trim, proceed on survivors | A3 |
| `> F` peers Byzantine | **Not detectable** — stated limitation | Envelope still binds (INV1); damage bounded, not prevented | A3 (compromised) |
| Full jamming, no peers, no LLM | Link quality | Deterministic escape only | A1 |
| Operator intervenes | MCP command | Operator command supersedes, LLM suspended for named vehicles | A4 |

The `> F` row is deliberately in the table. The honest claim is bounded damage via INV1, not detection.

## 11. Decisions still open

1. **Envelope `S_i` definition.** Static box constraints (altitude band, speed, max heading rate) are the
   cheapest and make INV1 trivially checkable. A control-barrier-function envelope is stronger and gives a
   continuous-time safety guarantee, but couples the gate to the vehicle dynamics and makes INV2 harder to
   demonstrate. Recommendation: static box for the ICC paper, CBF for the journal extension.
2. **Whether A3 requires unanimity among survivors or a simple majority.** Affects how often a jammed but
   honest swarm can act at all; measurable in Stage 7.
3. **Whether `G_r` is a fixed sparse topology or re-selected at runtime as links degrade.** Runtime selection is
   more defensible under jamming and is the differentiator flagged in Stage 1 §5.3, but adds a topology-agreement
   problem that is itself Byzantine-exposed.

## 12. Refinements from Stage 3 (added after `message_interface.md`)

Stage 3 computed r-robustness exhaustively for N = 3–7 and the results sharpen three statements above.

**12.1 Two different resilience conditions, not one.** §3 derived `|N_i^r| ≥ 2F+1` and hence `N ≥ 2F+2`. That
is the counting condition for *receiver-side trimming of F extremes*, and it is correct for that mechanism.
It is not the same as the graph condition for resilient consensus: W-MSR under the F-total model requires the
reasoning graph to be (F+1, F+1)-robust, which K₃ already satisfies at F = 1, while the F-local model requires
(2F+1)-robustness, which nothing below N = 5 satisfies. The paper must keep these apart:

- **scalar/continuous quantities** (severity estimates, link-quality maps) → W-MSR filtering, graph condition;
- **discrete intent quorum** (level A3) → counting condition, `F+1` consistent *peer* proposals.

The N = 3 conclusion is unchanged but its justification is the counting condition, not the graph condition:
with two peers and F = 1, a vehicle can retain at most one honest peer proposal, so A3 is unattainable without
counting the proposer's own vote — and counting it would let a single honest agreement authorise a formation
break. A3 therefore stays disabled at N = 3, which makes N = 3 an ablation point rather than an operating point.

**12.2 New rule G1 — the robustness assumption becomes a runtime precondition.**

> Level A3 is admissible at round *k* only if the reasoning graph observed at round *k* is (F+1, F+1)-robust.

The check is exhaustive over subset pairs and costs 5.8 ms at N = 7, so it runs every round at 1 Hz. This
closes a gap that every prior work in the Stage 1 matrix leaves open: robustness is assumed at design time
and never verified while links are being jammed. G1 makes A5 (graph robustness) a checked property of the
running system, and it degrades the swarm along the §9 ladder automatically as edges drop.

**12.3 The sparse reasoning graph needs a different justification.** With the 9-byte record of Stage 3, the
whole reasoning plane costs 3.0 kbit/s at N = 7 on a *complete* graph. Sparsifying to C(1,2) saves 1.0 kbit/s
and drops F_total from 3 to 1. Bandwidth no longer justifies sparsity at these swarm sizes; per-vehicle
inference cost (records entering the LLM context per round scales with degree) might, and that is a Stage 7
measurement. Until it is measured, `G_r` is complete-by-design and sparse-by-degradation.

## Corrections from Stage 6 (added after `integration_spec.md`, 2026-09-02)

1. **Authority admission order.** The lattice A0 < A1 < A2 < A3 < A4 remains the *trust* order, but
   admission is not the reverse of it. The autonomous escape (A1) is a **liveness fallback**, tried only
   after the inherited controller (A0) fails to verify, because the escape candidate exists whenever
   sensed severity is non-zero and would otherwise discard the controller's command in every jammed
   round. Admission descends A4 → A3 → A2 → A0 → A1 → brake (`gate_v3`, `integration_spec.md` §6.1).
2. **INV4 extends to the safety envelope.** The invariant was written against fusion weights; Stage 6
   shows it must also govern envelope thresholds — no sender-supplied quantity (e.g. a neighbour's
   reported speed) may enter a separation or connectivity margin. See `integration_spec.md` §6.4.
3. **The plane boundary is semantic/numeric as well as per-vehicle.** Within each vehicle the reasoning
   agent owns the discrete fields (intent, authority request, suspicion) and the vehicle agent owns the
   continuous ones (bearing, speed, altitude). Measured basis: `integration_spec.md` §4.6, §6.5.
